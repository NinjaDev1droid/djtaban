## ✨ Features

- 🖼️ **Hero section** — Live club photo background with dark overlay
- 🌍 **3 Languages** — English 🇬🇧 · Arabic 🇸🇦 · Hebrew 🇮🇱 (full RTL support)
- 🎵 **Mixcloud embeds** — 4 real mixes playable directly on the page
- ▶️ **YouTube gallery** — 4 video thumbnails in a 2×2 grid
- 📅 **Past Venues** — Add events with the **+** button, saves automatically
- 📱 **Fully responsive** — Works on phone, tablet, and desktop
- 📩 **Book Me button** — Opens email with subject pre-filled
- 💬 **WhatsApp link** — One tap to message on mobile
- 🎨 **Dark theme** — Professional black + orange design
